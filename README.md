# Сколько стоит учиться и жить в Дубае?

Калькулятор бюджета студента: 7 университетов Дубая, жильё, транспорт, еда.

🌙 **Сайт:** https://medelinchi-bit.github.io/dubai-calculator/

Сделано Мадиной — [Instagram @soy.madiina](https://www.instagram.com/soy.madiina/) · [TikTok @soy.madina](https://www.tiktok.com/@soy.madina)

## Что умеет

- Выбор университета, программы (Foundation / бакалавриат / магистратура) и специальности
- Жильё: студ. резиденция, шеринг, студия, апарт-отель — цена зависит от образа жизни и срока
- Транспорт: метро / трамвай или такси
- Merit-скидка на обучение
- Итог в месяц и в год в AED и разбивка по категориям

Цены на обучение, жильё и транспорт — осень 2026. Еда и «прочее» пока примерные.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Структура страницы |
| `style.css` | Оформление (тема «Ночной Дубай»), цвета — в начале файла |

| `og-image.png` | Картинка-превью для соцсетей |

## Как поменять цены

1. Открой `data.js` в любом текстовом редакторе.
2. Меняй только числа и тексты в кавычках, запятые и скобки не трогай.
3. Сохрани и открой `index.html` в браузере, чтобы проверить.

## Как открыть сайт у себя

Дважды щёлкни по `index.html` — он откроется в браузере. Ничего устанавливать не нужно.

## Как выложить обновление

В терминале, в папке проекта:

```bash
git add .
git commit -m "Обновила цены"
git push
```

Через 1–2 минуты изменения появятся на сайте.
